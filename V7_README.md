# ECC Tip & Information Management System — V7

Adds to V6:
- Super Admin overview dashboard.
- Role permission model for admin/supervisor/analyst/officer.
- Advanced search with text, status, risk, category, region, zone, woreda and date range.
- Case history/timeline API and UI.
- Authenticated attachment download route; public `/uploads` static exposure removed.
- Date-range CSV reporting controls.
- Region/zone/woreda fields on tips.

This is a development/starter build. Production deployment should include HTTPS, secret management, backups, malware scanning for uploads, security testing, audit retention, and approved organizational geographic reference data.
